# TEMPLATE PEDOMAN PENULISAN SKRIPSI

## PROGRAM STUDI TEKNIK INFORMATIKA – UNIVERSITAS PAMULANG

# 1. KONFIGURASI DOKUMEN

Jenis dokumen: Skripsi
Ukuran kertas: A4
Orientasi: Portrait

Margin:

* Atas: 4 cm
* Kiri: 4 cm
* Kanan: 3 cm
* Bawah: 3 cm

Font utama: Times New Roman
Ukuran font isi: 12 pt
Warna teks: Hitam
Perataan isi: Justify / rata kiri-kanan.

# 2. ATURAN PARAGRAF UTAMA

Font: Times New Roman
Ukuran: 12 pt
Alignment: Justify
Line spacing: 2 spasi
Spacing before: 0 pt
Spacing after: 0 pt

Awal paragraf menggunakan indentasi sebanyak 5 ketukan dari batas awal pengetikan.
Indentasi hanya berlaku pada BARIS PERTAMA paragraf, bukan seluruh paragraf.

# 3. HIERARKI HEADING

LEVEL BAB / HEADING 1:
Format "BAB III" lalu "METODOLOGI PENELITIAN" pada baris berikutnya.
Menggunakan angka Romawi. Huruf kapital seluruhnya (uppercase). Posisi Center. Bold.
Times New Roman 12 pt. Tidak diberi titik pada akhir judul. Tidak menggunakan underline.
Dimulai pada halaman baru (page break).

# 4. HEADING LEVEL 2 / SUBBAB

Format nomor: 1.1, 1.2, 2.1, 3.1 dan seterusnya.
Posisi sejajar dengan margin kiri bidang pengetikan. Left indent = 0.
Tidak boleh dibuat menjorok ke kanan. Times New Roman 12 pt. Bold.
Tidak menggunakan titik setelah nomor terakhir maupun akhir judul.

# 5. HEADING LEVEL 3 / ANAK SUBBAB

Format: 1.1.1 Judul Anak Subbab.
Posisi tetap sejajar dengan margin kiri. Left indent = 0.
Tidak mengikuti indentasi Heading 2, tidak semakin masuk ke kanan.
3.1 dan 3.1.1 harus memiliki posisi awal yang SAMA.

# 6. HEADING LEVEL 4

3.1.1.1 Judul — posisi tetap sama, Left indent = 0.
Paragraf setelahnya tetap menggunakan First Line Indent 5 ketukan.

# 9. PENOMORAN HALAMAN

Bagian awal menggunakan angka Romawi kecil (i, ii, iii, …).
Bagian utama mulai BAB I menggunakan angka Arab (1, 2, 3, …).
Pada halaman awal BAB nomor di tengah bawah; halaman biasa di kanan atas.

# 10. BAGIAN AWAL SKRIPSI

Urutan dokumen:
1. Halaman Sampul
2. Halaman Judul
3. Halaman Judul dengan Spesifikasi
4. Halaman Pernyataan Bukan Plagiat
5. Halaman Persetujuan
6. Halaman Pengesahan
7. Abstract Bahasa Inggris
8. Abstrak Bahasa Indonesia
9. Kata Pengantar
10. Daftar Isi
11. Daftar Gambar
12. Daftar Tabel
13. Daftar Lampiran
14. Daftar Istilah jika diperlukan

# 27. DAFTAR PUSTAKA

Format sitasi mengikuti APA Style sesuai pedoman program studi.
Baris pertama referensi 0 cm dari margin kiri; baris berikutnya hanging indent sekitar 5 ketukan.
Line spacing: 1 spasi. Judul buku dan nama jurnal ditulis Italic.

# 29. LIST / POIN BERTINGKAT

Level pertama angka (1.), level kedua huruf (a.), level ketiga angka lagi, dan seterusnya.

# 30. PAGE BREAK

Setiap BAB baru wajib menggunakan Page Break. DAFTAR PUSTAKA = halaman baru.

# 39. PRINSIP UTAMA TEMPLATE

Heading bukan indentation hierarchy. Heading 2, 3, 4 tetap dimulai dari margin kiri yang sama.
Yang menunjukkan hierarki adalah nomor heading, struktur dokumen, dan daftar isi.
Paragraf isi memiliki indentasi pada BARIS PERTAMA sebanyak 5 ketukan.
